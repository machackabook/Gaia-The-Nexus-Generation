- Pass 1: broad Drive inventory, chronology anchors, GitHub backend correlation.
- Later passes: deeper source reads, deduplication, implementation mapping, and GaiasWindow convergence.

## Provenance rules

1. Preserve source names and dates when observed.
2. Distinguish authored architecture from generated diagnostics and crash material.
3. Do not copy secrets, OAuth tokens, API keys, private Drive URLs, or machine credentials into GitHub.
4. Treat aspirational design documents as design evidence, not proof of deployed functionality.
5. Prefer additive documentation and reviewable pull requests over silent rewrites.
