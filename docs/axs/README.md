# NEXUS AXS public mirror v5.1

This path is a **public visualization surface**. It intentionally contains no private agent, native installer, credentials, device telemetry, or remote shell.

## Deployment

- GitHub Pages: enable **main /docs** under repository Pages settings and browse `/axs/`.
- Vercel: set project rootDirectory to `docs/axs`, framework Other/static.
- Android and iPhone: install this site as a PWA using supported browser actions.

The complete offline-capable v5.0 source ZIP and monolithic local Termux installer are distributed separately. This public v5.1 companion uses CDN-hosted Three.js r128 for WebGL, with a local 2D Canvas fallback. It never claims private-machine metrics.
