# [TDOC][SS-SV9-CANONICAL-POLICY-V6.3]

All new GAIA operational scripts must have a TDOC header, install their own checked and versioned copy under GAIA/autonomous, log append-only evidence to GAIA/logs, and use a reviewable SS/SV9 sentinel sequence. Gates run in order; a verified passing gate may advance to the next allowlisted step. On failure, stop, record a structured remedy card, preserve raw evidence locally, and publish only sanitized diagnostics to a private repository with confirmed access. AI-authored remedies are proposals until independently tested and approved. No automated destructive imaging or firmware changes. Source is pulled from GitHub; local diagnostics are committed to private GitHub only after sanitization and authentication checks. Maintain backup, fingerprints, rollback and explicit user review for impactful changes.
